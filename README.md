# Framework de Carreira · Product Design · Matera

Ferramenta interativa do framework de carreira de Product Design: uma régua de níveis (PD1–PD4), autoavaliação comportamental e técnica, e geração de um PDI pronto para oficializar na Qulture Rocks.

## 🔗 Acessar

**[matera-aml.github.io/framework-carreira-productdesign](https://matera-aml.github.io/framework-carreira-productdesign/)**

## O que tem aqui

- **A régua** — os 8 pilares comportamentais, sinais de alerta por nível e a matriz completa (soft skills + hard skills).
- **Meu mapa** — autoavaliação de 15 perguntas, evidências do nível atual, próximo nível almejado e plano de desenvolvimento.
- **PDI** — baixa um arquivo Word (.docx) pronto para anexar na Qulture Rocks.

## Como funciona

Página estática, sem backend: as respostas ficam salvas no navegador de cada pessoa (nada é enviado a um servidor). Cada um só vê o próprio progresso.

## Atualizar o conteúdo

Substitua o arquivo `index.html` neste repositório por uma nova versão — o GitHub Pages publica a atualização automaticamente em 1–2 minutos.
